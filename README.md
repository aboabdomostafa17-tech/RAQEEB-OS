RAQEEB-OS is an advanced AI-powered security and attendance system. It utilizes Face Recognition technology to monitor premises, log attendance automatically, and provide real-time security alerts.

🚀 Key Features
Face Recognition: Identifies registered individuals in real-time with high accuracy.

Pro Interface: Modern GUI built with CustomTkinter for easy control.

Automated Logging: Saves entry and exit timestamps directly into an Excel sheet, optimized to prevent redundant logs.

Telegram Integration: Sends instant photo alerts and notifications to your phone when an intruder is detected.

Sound Alarm: Triggers an audible warning (alarm.mp3) for unauthorized access.

Live Dashboard: Real-time counters for Allowed vs Unknown individuals.

🛠️ Built With
Python: The core programming language.

CustomTkinter: For the professional modern UI.

OpenCV & Face_Recognition API: For computer vision and face detection.

Telepot: For Telegram Bot communication.

Pandas: For seamless Excel data management.

⚙️ Installation & Usage
Clone the Repository:

Bash
git clone https://github.com/aboabdomostafa17-tech/RAQEEB-OS.git
Install Dependencies:

Bash
pip install -r requirements.txt
YOLO Model:

Please download the yolov8n.pt model file and place it in the project root directory.

Run the Application:

Execute the main file:

Bash
python Raqeeb_pro.py
⚠️ Security Note
Make sure to keep your secret.key and Telegram tokens private. Do not share them in public repositories.
